## 补齐苍穹外卖后端缺失模块（订单 / 统计报表 / 工作台 / 定时任务）

### 背景
项目此前只完成到「用户商品浏览」，订单、统计报表、工作台、定时任务四个模块整体缺失；
POJO 层（DTO/VO/entity）与 `OrderService` 接口、`OrderMapper` 接口已提前写好，缺的是实现层。

### 新增文件
- `service/impl/OrderServiceImpl.java`：14 个方法的完整实现（下单、支付、历史订单、详情、用户取消、
  再来一单、催单、条件搜索、状态统计、接单、拒单、管理端取消、派送、完成）
- `controller/admin/OrderController.java`、`controller/user/OrderController.java`
  （Bean 名必须显式区分为 `adminOrderController` / `userOrderController`，否则同名类 Bean 冲突）
- `service/ReportService.java` + `service/impl/ReportServiceImpl.java` + `controller/admin/ReportController.java`
- `service/WorkspaceService.java` + `service/impl/WorkspaceServiceImpl.java` + `controller/admin/WorkspaceController.java`
- `task/OrderTask.java`：超时未支付订单自动取消（每分钟）、派送中订单自动完成（每天 01:00）
- `resources/mapper/UserMapper.xml`（新增 `countByMap`，按 `create_time` 统计新增用户）

### 修改文件
- `SkyApplication.java`：新增 `@EnableScheduling`
- `mapper/UserMapper.java`：新增 `countByMap(Map)`
- `resources/mapper/OrderMapper.xml`：insert 补上 `address`、`user_name` 两列（与 DB schema 一致）
- `resources/mapper/ CategoryMapper.xml` → `CategoryMapper.xml`：**修复文件名前导空格**
  （会导致跨平台构建异常，且 `target/` 残留旧文件时会触发 MyBatis「Mapped Statements already contains」重复映射错误）

### 关键实现决策
- **微信支付改为模拟回调**：项目未配置商户号/证书，`payment()` 直接调 `paySuccess()` 置为已支付并返回
  占位 `OrderPaymentVO`，保证下单主流程可完整联调；退款同样只落 `pay_status=2` 并打日志。
- **Excel 导出不依赖模板**：原课程用 `template/运营数据报表模板.xlsx`，本项目无该资源，
  改为用 POI 从零构建工作簿（标题/统计区间/概览/逐日明细），并在响应头设置 attachment 下载。
- **报表未新建 ReportMapper**：复用 `OrderMapper.sumByMap/countByMap/getSalesTop10` 与
  `UserMapper.countByMap`，避免冗余。
- 用 `Collectors.joining(",")` 替代 commons-lang 的 `StringUtils.join`，不引入额外依赖。
